## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Python-Codes.git
```

### 2. Open the repository

```bash
cd Python-Codes
```

### 3. Run any Python file

```bash
python filename.py
```

Make sure **Python 3** is installed on your computer.
